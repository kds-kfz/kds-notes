### 步骤 1.2：数据查看

### 步骤 1.3：接口测试实现

- 状态：`IMPLEMENTED`
- 独立配置固定使用 `MtLoadTest/conf/interface-test.xml`，不复用或写入 `MtLoadEngine/conf`。

1. `InterfaceTestConfig` 加载 Environment、Server、VariableSet、Case、Header、Field、Extract，并验证引用和唯一 id。
2. `TransportPayloadMatrix` 过滤协议；HTTP/HTTPS 下不显示 Binary，未实现组合禁止发送。
3. 字段表与原始 JSON 通过 JSON Pointer 双向同步，必填字段不可关闭/删除，敏感字段默认脱敏。
4. SocketClient 在后台线程中通过 HPSocket 执行 HTTP/HTTPS；HTTPS 启用 TLS 并默认校验对端证书。
5. SocketClient/HPSocket WebSocket 适配支持 ws/wss、10001 首次绑定及 30 秒心跳、10002/10003 请求和 10004 只读展示。
6. `/verify_password` 按 `/Data/Token` 提取 Token 到内存会话，后续请求填充 `${Token}`。
7. 保存先生成同目录临时文件，执行 UTF-8/XML 复检，再使用原子替换；失败保留原文件。

### 步骤 2：DLL 加载、ABI 校验和生命周期

- 状态：`IMPLEMENTED`
- 前置条件：`MtLoadEngine.h` 和可加载 DLL 已提供。
- 涉及文件：`engine/LoadEngineClient.*`、`engine/RunController.*`。
- 实施：解析导出、查询 ABI、创建/销毁句柄、转换 UTF-8 错误。
- 完成标准：DLL 缺失或不兼容时可编辑配置但不能启动；退出无句柄泄漏。
- 测试：公共头、导入库和运行时 DLL 已同步到 `vender/MtLoadEngine`；Release x64 构建、PostBuild 依赖复制和程序启动 smoke 通过。缺失 DLL、缺导出和 ABI 不匹配专项测试待补。

### 步骤 3：参数编辑边界

- 状态：`OUT_OF_SCOPE`
- 决策：线程、循环、环境、账号、步骤、请求头和请求正文只在 XML 中编辑。
- 界面只读取 DLL 返回的环境/场景/用户安全摘要，不建立计划 DOM、属性页或账号表格。
- 验证：源码未引入 XML 解析器，MFC 不持有密码和 Token。

### 步骤 4：XML 浏览、加载和重新加载

- 状态：`IMPLEMENTED`
- 实施：浏览只选择并显示 XML 绝对路径；“加载”每次重新调用 DLL LoadPlan/ValidatePlan，并刷新环境、场景和用户列表。
- 完成标准：MFC 不保存或回写 XML；修改配置后终止本轮并再次加载即可生效。
- 测试：非法 XML 和引用错误由 DLL 返回；中文路径仍需测试环境人工验收。

- 测试：环境/场景/用户下拉、Start/Stop/Pause/Resume 和 1000 ms 状态/指标刷新已构建验证；多 DPI 人工验证待完成。
