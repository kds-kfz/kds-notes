# 指标绘图压测场景实施方案

## 场景

- 图表绘图、图表指标、图表配置分别按 `OptType=1、3、4、2` 执行新建、修改保存、查询、删除。
- 图表绘图批量同步只按接口能力执行 `OptType=1、2`。
- 每个场景默认 10 个线程、每线程 10 次循环，界面只负责选择，参数继续由 XML 管理。

## 数据隔离和清理

- ID 使用 `loadtest-{类型}-${runId}-${threadIndex}-${iterationIndex}`，允许多个线程复用同一账号。
- 删除步骤只携带本轮明确 ID，并设置 `alwaysRun=true`；禁止用空 ID 执行范围删除。
- `ChartSymbolId` 和 `ChartInterval` 由选中 User 的 Param 提供。

## 配置归属

- 唯一源文件为 `MtLoadTest/conf/v3-http.xml`，并作为 `None` 项归入“配置文件”筛选器。
- Release 和 ReleaseStatic 构建都复制到各自输出目录的 `conf/v3-http.xml`。
- `MtLoadEngine/conf` 不保存该业务计划。

## 验收

- XML 可解析、引擎校验通过，界面显示新增四个中文场景。
- 正常生命周期每循环四个请求，批量同步每循环两个请求。
- 使用 MT4、MT5 用户真实联调时分别确认修改后的数据可查询且删除后无残留。
