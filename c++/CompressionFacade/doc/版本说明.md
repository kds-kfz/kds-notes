# CompressionFacade 版本说明

## 2026-10-22 1.0.0 初始实现

- 新增稳定 C ABI 和内部压缩 Codec 抽象工厂。
- 新增 Snappy 最大长度、压缩、原始长度读取和解压接口。
- 新增输入、输出上限以及动态/静态双构建配置。

## 2026-10-22 1.0.1 内部静态组件收敛

- V3 生产产物改为 `CompressionStatic.lib`，由 CloudNetDataApi 唯一吸收，不单独发布 Compression DLL。
- Release DLL 只保留兼容构建；Snappy 仍由本组件封装，业务源码禁止直接包含 Snappy 头文件。

## 2026-10-22 1.0.1.0 发布元数据与目录规范

- Release 兼容 DLL 统一输出到 `lib/x64vc14/dynamic`，根目录不再作为有效产物来源。
- 兼容 DLL 增加 `1.0.1.0` 文件版本和产品版本；V3 生产仍由 CloudNetDataApi 私有吸收
  `CompressionStatic.lib`。
