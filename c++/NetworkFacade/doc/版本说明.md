# NetworkFacade 版本说明

## 2026-10-22 1.0.0 初始聚合边界

- 新增 Facade ABI 与网络能力查询结构，所有字段带用途、范围和所有权说明。
- 私有静态吸收 SocketServer、SocketClient 和 HP-Socket，OpenSSL 3.5.6 保持动态。
- 保留旧网络工厂 C 导出作为 V3 迁移期兼容入口，不允许新增业务扩大 C++ 虚表 ABI。

## 2026-10-22 1.0.0.0 发布元数据与目录规范

- Release 动态产物统一输出到 `lib/x64vc14/dynamic`，该目录同时包含 DLL、导入 LIB 和 PDB。
- DLL 增加 `1.0.0.0` 文件版本和产品版本，便于完整发布包执行版本与哈希门禁。
- V3 仍只动态使用 NetworkFacade；SocketServer、SocketClient 和 HP-Socket 继续由本 DLL 唯一静态吸收。

## 2026-10-22 1.0.1.0 唯一所有权收口

- SocketServer 私有实现不再依赖 `libnsdk_static.lib`、`common.lib`、`crash_generation_client.lib` 或 `exception_handler.lib`。
- NetworkFacade 删除 nsdk/Breakpad 头文件目录、库目录、预处理宏和链接项；进程崩溃处理继续由最终 EXE 唯一负责。
- 保持 SocketServer ABI 7、SocketClient ABI 4 和全部迁移期兼容导出不变；实现版本更新为 `1.0.1`。
- `Release|x64` 在 VS2022 v143、C++17、`/MD`、`/W4 /WX` 下重新构建成功，0 警告、0 错误。
- `libNetworkFacade.dll` 为 904,192 字节，SHA-256 为 `6608C2E0C840A7205363E19701DBE1835400DA05EB0BB53C7E82A4C3E46BFFD6`。

## 2026-10-23 1.0.1.1 pthreads-w32 当前依赖收敛

- 私有 SocketServer 实现的普通进程内同步改用 C++17 标准线程原语，NetworkFacade 当前构建不再链接
  `pthreadVC2.lib`，运行时也不再导入 `pthreadVC2.dll`。
- 这不是永久禁用 pthreads-w32；后续 Provider 确需其专有能力时，可以在本 Facade 作为唯一最终所有者、
  补齐动态依赖和回归门禁后重新引入。
- `Release|x64` 在 VS2022 v143、C++17、`/MD`、`/W4 /WX` 下重新构建成功，0 警告、0 错误。
- `libNetworkFacade.dll` 为 908,288 字节，SHA-256 为
  `5B2EB1133D8278172D2E5A6D8D1341AE59D10D0DB0E7FB2B25FB47416CAB9370`。
