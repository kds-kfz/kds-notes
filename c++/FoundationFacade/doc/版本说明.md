# FoundationFacade 版本说明

## 2026-10-22 1.0.0 初始实现

- 新增稳定 C ABI、Windows/Linux Provider 抽象工厂和平台句柄。
- 新增日期、休眠、文件存在、目录存在、递归建目录和路径分隔符接口。
- 新增 DLL 与静态兼容库构建配置；私有吸收 nsdk 静态实现。

## 2026-10-22 1.0.1 内部静态组件整改

- V3 生产产物收敛为 `FoundationStatic.lib`，不再发布 Foundation DLL。
- 移除对完整 nsdk、Breakpad、日志和线程运行时的依赖，日期、休眠、文件和目录能力改用标准库实现。
- Release DLL 只保留兼容构建；生产依赖所有权由最终领域 Facade 负责。

## 2026-10-22 1.0.1.0 发布元数据与目录规范

- Release 兼容 DLL 统一输出到 `lib/x64vc14/dynamic`，根目录不再作为有效产物来源。
- 兼容 DLL 增加 `1.0.1.0` 文件版本和产品版本；V3 生产仍只私有吸收 `FoundationStatic.lib`。
