# snappy 版本说明

## 2026-10-12 本地未提交改动汇总

### 实现内容

- 公共头补充 `SNAPPY_STATIC`、`SNAPPY_EXPORTS` 和普通 DLL 调用方的导出宏分支。
- VS2022 新增 `ReleaseStatic|x64`，统一使用动态 CRT `/MD`，输出
  `lib/x64vc14/static/libsnappy_static.lib/pdb`。
- `Release|x64` 继续输出 `libsnappy.dll/lib/pdb`，动态与静态产物分目录保留。
- VS2010、VS2015、VS2022 的版本资源公司名称统一为
  `Shenzhen Guangwz Technology Co., Ltd.`，文件描述保持英文，不再使用错误中文公司名。
- V3 和 IceRPCPush 按当前策略使用静态 snappy，其他旧调用方仍可继续使用 DLL。

### 验证与风险

- 动态、静态输出目录均已有本轮构建产物。
- 静态调用方必须定义 `SNAPPY_STATIC` 并保持 `/MD`；禁止与 `/MT` 对象混合跨库分配释放。
