# FacadeCommon 版本说明

## 2026-10-22 1.0.0 稳定 Facade C ABI 公共契约

### 初始内容

- 新增 `FacadeAbi.h`，集中定义 `FACADE_ABI_VERSION=1`、稳定返回码、只读 UTF-8/二进制视图、调用方
  可写缓冲区和 ABI/实现版本信息结构。
- 所有跨 DLL 结构均携带 `uiStructSize`、`uiAbiVersion`、`uiFlags` 和零初始化保留字段；输入和输出内存
  所有权留在调用方，避免 STL、异常或 CRT 分配对象跨越 DLL 边界。
- 已由 CompressionFacade、CredCore、DatabaseFacade、FoundationFacade 和 NetworkFacade 的稳定 C ABI
  复用；IceRPCPush 的私有兼容层通过对应 Facade 头间接使用相同契约。

### 兼容规则

- 已发布返回码数值和结构字段不得修改或重排；新增返回码只能追加，结构扩展优先使用保留字段和
  `uiStructSize` 协商。
- `FACADE_ABI_VERSION` 只在不兼容契约变更时递增；实现版本和依赖版本通过 `ST_FACADE_ABI_INFO` 独立报告。
- FacadeCommon 是头文件契约，不单独生成或发布 DLL/LIB。

## 2026-10-29 版本说明补齐

- 本地工作树一致性复核发现 FacadeCommon 已被多个 Facade 使用，但此前没有自身版本说明，本条补齐该遗漏。
- 本次只新增文档，没有修改 `FacadeAbi.h`，也没有重新构建各 Facade；消费者构建和 ABI 回归仍以各自项目的
  版本说明与测试记录为准。
