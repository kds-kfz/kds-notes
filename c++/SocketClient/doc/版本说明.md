# SocketClient 版本说明

## 2026-10-12 HP-Socket 6.0.9 与动态/静态双模式改造

### 网络能力

- Vendor 更新为 HP-Socket 6.0.9，同步动态 DLL/LIB/PDB，并保留使用 `/MD` 编译的静态 HPSocket LIB/PDB。
- ABI 升级为 4，新增 HTTPS、WSS 工厂、TLS CA 链配置、WebSocket 自定义升级头和线上正文大小字段。
- HTTP 响应支持 gzip、zlib/deflate 解压；业务回调接收解压正文，完成事件保留解压前线上字节数。
- 同一 HTTP/HTTPS 实例增加单在途请求闸门；完成、失败、关闭和停止路径均释放闸门，避免无请求 ID
  的回调与重叠请求发生错误关联。
- 连接、重连、Stop、实例删除和异步回调生命周期重新收敛，运行时信息增加安全连接标记。

### 构建与发布

- `Release|x64` 继续输出 `lib/x64vc14/share/libSocketClient.dll/lib/pdb` 并依赖 `HPSocket.dll`。
- `ReleaseStatic|x64` 输出 `lib/x64vc14/static/libSocketClient_static.lib/pdb`，定义
  `SOCKETCLIENT_STATIC`、`HPSOCKET_STATIC_LIB`，最终程序不再依赖 `libSocketClient.dll` 或 `HPSocket.dll`。
- 动态、静态配置统一使用动态 CRT `/MD`；动态模式保留自身 zlib 对象，静态模式复用 HP-Socket
  静态归档中的 zlib，避免同名符号重复。
- DLL 公司信息统一为 `Shenzhen Guangwz Technology Co., Ltd.`。

### 验证与限制

- 动态和静态真实 TCP、HTTP、WebSocket 回环测试通过；覆盖 Keep-Alive 顺序请求、重叠请求拒绝、
  TLS 工厂、压缩响应和 32 轮创建/连接/收发/销毁资源回落。
- 官方 HP-Socket 6.0.9 客户端可验证 CA 链并设置 SNI，但不校验证书主机名；不能将该能力描述为严格站点身份认证。
- Linux Makefile 已保留，但本轮未完成 Linux 依赖、编译和实机联调，不能标记为可交付。

## 2026-10-21 当前版本 1.0.0.1（ABI 4）成员命名规范整改

### 调整内容

- `ClientInstance`、TCP/HTTP 监听器及运行时测试中的成员变量统一使用 `m_` 加区域/类型前缀，删除尾下划线命名。
- 本次只调整私有实现标识符，不修改公共 C ABI、导出函数、数据结构布局、HP-Socket 6.0.9 依赖或运行行为。
- 工程规范审计新增成员命名门禁；官方、第三方和需保持跨平台 ABI 的历史源码不做机械改名。

### 验证结果

- `Release|x64` 与 `ReleaseStatic|x64` 均构建成功。
- 动态、静态 `SocketClientRuntime` 均输出 `SocketClient multi-instance TCP/HTTP/Web: PASS`。
- 版本说明沿用追加式维护：既有记录保持原位，新记录只写在文件末尾。

## 2026-10-29 当前版本 1.0.0.1 OpenSSL vendor 目录规范化

### 调整内容

- VS2022 动态工程的 OpenSSL 头文件和导入库路径由
  `vender/openssl/3.5.6/...` 调整为统一的 `vender/openssl/...`。
- `SocketClientRuntime` 静态测试工程同步使用新导入库路径，动态测试的 post-build 复制路径同步指向
  `vender/openssl/bin/x64vc14/dynamic`。
- Git 中旧 `3.5.6` 目录删除与新目录新增属于同一 OpenSSL 3.5.6 内容的目录迁移，不表示删除 OpenSSL
  依赖或升级第三方版本。
- 本次不修改 SocketClient 源码、公共 C ABI、ABI 4、TLS 行为、HP-Socket 版本或动态/静态发布边界。

### 验证与风险

- 静态核对确认工程只变更 OpenSSL include/lib/bin 路径，新目录存在 `libssl-3-x64.dll`、
  `libcrypto-3-x64.dll` 及对应头文件。
- 本次版本说明复核没有重新执行 SocketClient 动态/静态构建或运行时测试；当前 PDB 变更属于既有构建产物，
  不能替代可重复的构建与回归记录。
