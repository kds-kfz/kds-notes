# 启动、停止与双链路隔离

## 1. 范围与状态

描述 Reliable、Broadcast 和 Best Effort 三个组件的启停及资源所有权。第一阶段只启动 Reliable 和 Best Effort，Broadcast 显式禁用；真实 NATS 连接和故障恢复待验收。

| 项目 | 内容 |
| --- | --- |
| 输入 | MarketEvent、Broadcast、ReliableEvent 配置和 CloudNet 生命周期 |
| 输出 | `1172-1175`、`1211/1251/1252` 在线中继和 READY/失败状态 |
| 线程/队列 | Market 固定分片线程；JetStream API 由请求线程并发调用；Broadcast 第二阶段才启动 |
| 所有权 | 三个组件分别拥有自己的队列、线程和 NATS 连接，禁止共享消息句柄 |

| 组件 | 资源 | 失败行为 |
| --- | --- | --- |
| Reliable Store | 独占 NATS 连接、JetStream Context、Pull Subscription 和 pending message | test 必需时失败阻止启动；dev 可禁用 |
| Broadcast Bus | 独占 Core NATS 连接、普通订阅和接收线程 | 关闭时允许单实例本地直通 |
| Market Relay | 固定分片、可配置队列和工作线程 | 容量 0 不主动淘汰；正容量满载淘汰最旧 Tick 并计数 |

## 2. 启动

~~~
graph TD
    A["公共框架加载网络和Cluster"] --> B["OnConfigure解析Market Broadcast Reliable"]
    B --> C{Reliable enable}
    C -- 是 --> D["连接NATS并取得JetStream Context"]
    D --> E["创建或严格更新交易事件Stream"]
    C -- 否 --> F["记录Reliable DISABLED"]
    E --> G["确认第一阶段Broadcast关闭"]
    F --> G
    G --> H["创建Best Effort固定分片和工作线程"]
    H --> I["开放1172到1176和1211回调"]
    I --> J["服务READY"]
~~~

## 3. 停止

~~~
graph TD
    A["撤销服务READY"] --> B["拒绝新的1172到1175"]
    B --> C["等待共享NATS调用退出"]
    C --> D["释放pending消息和Pull订阅"]
    D --> F["关闭Best Effort入队闸门"]
    F --> G["排空已受理行情分片"]
    G --> H["等待全部工作线程退出"]
    H --> I["释放NATS CloudNet和日志资源"]
~~~

未 ACK JetStream 消息不在停机时强制 ACK，消息句柄释放后由 JetStream 后续重投。
