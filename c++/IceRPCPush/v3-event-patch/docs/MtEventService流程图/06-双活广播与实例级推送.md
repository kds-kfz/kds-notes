# 第二阶段双活广播与实例级推送

## 1. 范围与状态

本页是第二阶段保留设计，第一阶段 dev/test 的 Cluster 和 Broadcast 均关闭，`1211/1251/1252` 只在单 Event 实例本地 Ice 扇出。第二阶段启用双活后，任意实例收到事件再写共享 Core NATS Subject，各 Event 实例使用普通订阅而非 queue group，随后只向连接到自己的 Ice 客户端扇出；跨机双活尚未验收。

| 项目 | 内容 |
| --- | --- |
| 输入 | 已校验的 `1211/122x/124x/1251/1252` 通知和来源实例 ID |
| 输出 | 所有 Event 实例各自本地 Ice 订阅者收到一次在线通知 |
| 线程/队列 | Publish 调用线程本地交付；每实例一个同步 Core NATS ReceiveThread |
| 所有权 | BroadcastBus 独占 NATS 连接、普通订阅和有界 EventId 去重窗口 |

## 2. 广播拓扑

~~~
graph LR
    S1["Quote Trade或Derive事件"] --> E1["Event实例1"]
    E1 --> N1["Core NATS Broadcast Subject"]
    N1 --> E1
    N1 --> E2["Event实例2"]
    E1 --> C1["连接实例1的Gateway或Query"]
    E2 --> C2["连接实例2的Gateway或Query"]
    I1["IceGrid副本组"] -. 建立连接 .-> E1
    I1 -. 建立连接 .-> E2
~~~

## 3. 去重与回环保护

~~~
graph TD
    A["本实例准备Publish"] --> B["编码来源实例和确定性EventId"]
    B --> C["先登记有界去重窗口"]
    C --> D["本地低延迟交付一次"]
    C --> E["发布Core NATS"]
    E --> F["本实例和其他实例ReceiveThread接收"]
    F --> G{EventId已存在}
    G -- 是 --> H["忽略本地回环或重复"]
    G -- 否 --> I["登记并调用OnBroadcastEvent"]
    I --> J["PublishPluginNotification到本实例订阅者"]
~~~

广播只提供在线复制，不替代 JetStream 可靠持久化。
