# 六服务逻辑架构

## 1. 第一阶段职责

- Gateway：HTTP/Web 鉴权、校验、Binary/JSON 转换和路由，不计算业务。
- Quote：原始行情连接、Tick 接收、SourceEpoch/Sequence、FIFO、1211 和 1124。
- Trade：交易命令、预检和权威交易状态。
- Query：普通查询、历史查询、时间权威和 PostgreSQL ClientData。
- Event：单实例在线通知校验与本地 Ice 中继，以及单副本 JetStream 可靠事件治理。
- Derive：quotes 快照、M1、OpenPrice、Profit、回填和归档的目标 Owner。
