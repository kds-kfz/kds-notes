# 查询、交易、行情、收益端到端链路

## 1. 行情目标链路

~~~
graph LR
    MT["MT4和MT5 Tick"] --> Q["Quote单连接接入"]
    Q -->|"1211 Quote Tick Binary v1"| E["Event在线分发"]
    E --> G["Gateway实时Quote"]
    E --> D["Derive去重和缺口识别"]
    D --> S["quotes快照 双槽M1 OpenPrice"]
    D -->|"1168缺口回填"| R["Query HISTORY_QUERY"]
    R --> MT
    S -->|"1252"| E
    S --> A["归档"]
    A --> R
~~~

Quote 重启或原连接恢复会旋转 SourceEpoch。Event 通过 `1176` 暴露逐来源水位；Derive 后续结合 `1124/1176` 心跳、Epoch 变化和 Sequence 缺口安排延迟补数，补数期间继续接收新 Tick。

## 2. 查询和交易

HTTP 查询仍由 Gateway 路由到 Query，交易由 Gateway 路由到 Trade；这两条链路不借用 Quote SDK 连接。Query 的时间权威、旧行情冷启动和 Derive 消费者迁移不在本轮执行。

## 3. 状态

Quote/Event 源码和配置完成不等于六服务链路完成。真实 MT、IceGrid、Event 消费者、/quotes、/bars、Web Quote 和断线补数验证全部形成报告后，才能提高联调状态。
