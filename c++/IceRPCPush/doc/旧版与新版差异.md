# IceRPCPush 新旧差异

## 旧版

- 目录：`F:\kingdom\trunk\ice\JsoniRPCPush`
- Ice 版本：3.5.1
- 配置：Ice `.properties` 和 `[ICEPUSH]` INI 混合在同一个配置文件里读取。
- TCP 推送：旧 `s.dll/s.lib` 接口。
- 日志：工程内旧 `CLog::Instance().Open/WriteLog/Close` 文件日志。

## 新版

- 目录：`F:\开发资料\MyCode\kds-notes\c++\IceRPCPush`
- Ice 版本：3.8.2，Slice 生成代码使用新版 proxy、`AByte` 和 async 接口。
- TCP 推送：通过 `src\compat\SocketServerCompat.cpp` 兼容旧 `s_create/s_send/s_close/s_destroy/s_compare`，底层走 `SocketServer`。
- 压缩：snappy 使用 `vender\snappy`；zlib/json 使用新版工程 `vender` 下的库。
- 配置：保留旧 `.properties/INI` 兼容，同时新增 XML 配置。扩展名为 `.xml` 时按 `doc\IceRPCPush.sample.xml` 解析。
- 日志：保留旧 `CLog::Instance().WriteLog` 调用外观，底层适配 `SocketServer\src\Log.h/.cpp` 的异步日志类。

## XML 配置映射

- `<Ice><Property name="Identity" value="..."/></Ice>` 等价于旧 `Identity=...`。
- `<Ice><Property name="JsonBinRPCSZSH.Endpoints" value="..."/></Ice>` 等价于服务端 endpoint 配置。
- `<Ice><Property name="JsonBinRPCSZSH" value="..."/></Ice>` 等价于客户端 proxy 配置。
- `<Ice><Property name="JsonBinRPCSZSH.Client.Endpoints" value="..."/></Ice>` 等价于客户端双向回调 adapter 配置。
- `<ICEPUSH><RPCPushBindport>...</RPCPushBindport></ICEPUSH>` 等价于旧 `[ICEPUSH] RPCPushBindport=...`。
- `RPCPushmax` 非法或小于等于 0 时回退 `1000`。
- `RPCXThreadNum` 非法或小于等于 0 时回退 `3`。
